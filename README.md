## FAQ

### What is XCutors?

XCutors is a Windows desktop application that bundles multiple popular Roblox script executors — Volt, Synapse Z, Potassium, and Wave — along with a universal loader called xcutorsLoader, giving you one convenient place to manage and run Lua scripts.

### Is XCutors free to use?

Yes. The xcutorsLoader and the bundled open-source executors are completely free. Some individual executors may have their own premium tiers; please check each executor's official page for details.

### Which Roblox versions are supported?

XCutors is tested against the latest stable Roblox Windows client. After a Roblox update, executors may require a brief patching period — the auto-update system handles this automatically in most cases.

### How do I update the executors?

xcutorsLoader checks for updates every time it launches. If a new version of any bundled executor is available, you will be prompted to update with a single click. You can also manually check via Settings → Check for Updates.

### Can I use my own custom Lua scripts?

Absolutely. You can paste scripts directly into the editor, drag and drop .lua files from your computer, or load scripts from a URL. The built-in script hub is entirely optional.

### Why is my anticomponent flagging XCutors?

Script executors use techniques such as DLL injection that are commonly flagged by anticomponent heuristics. This is a false positive. To resolve it, add the XCutors folder to your anticomponent exclusion or whitelist. Always download XCutors from this official GitHub repository.

### The executor fails to attach or inject. What should I do?

First, make sure you are running xcutorsLoader as Administrator. Second, confirm that Roblox is open and you have joined a game. Third, temporarily disable or whitelist XCutors in your anticomponent. If the issue persists, check the latest release notes — a Roblox update may have caused a temporary incompatibility.

### Where can I find more scripts?

XCutors includes a built-in script hub with hundreds of community-contributed scripts. You can also find scripts on popular Roblox scripting forums and community Discord servers. Always review scripts before executing them.

### Does XCutors work on macOS or Linux?

No. XCutors and all bundled executors are designed exclusively for Windows (64-bit). There are no current plans for cross-platform support.

### How do I report a bug or request a feature?

Please open an issue on the GitHub Issues page with a clear description, steps to reproduce, and your system information. Feature requests are also welcome and tracked in the same issue tracker.
